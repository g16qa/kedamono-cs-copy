# kedamono-cs-copy

Notionで管理しているケダモノオペラのキャラクターシートを、Discordに貼れる形式でクリップボードにコピーするためのページです。

公開ページ: https://g16qa.github.io/kedamono-cs-copy/

## 仕組み

1. Notionデータベースの「コピー」列（数式）が、シートの内容をURLの `#` 以降に入れたリンクを作ります。
2. リンクを開くと [index.html](index.html) が `#` 以降を読み取り、クリップボードにコピーします。
3. 自動コピーがブラウザに拒否された場合は、ページをクリックするとコピーします。

`#` 以降はサーバーに送信されません。ただしリンクそのものにシートの内容が含まれるので、リンクを共有すると内容も伝わります。

## Notion側の設定

データベースには次のプロパティが必要です。

| プロパティ | 種類 | 備考 |
|---|---|---|
| ケダモノ名 | タイトル | |
| ケダモノ種/亜種 | テキスト | |
| 権能 | マルチセレクト | |
| 疑似餌の姿 | テキスト | |
| 欲望 | テキスト | |
| 住処 | テキスト | |
| 伝説 | テキスト | |
| 弱点 | テキスト | |
| 弱点の影響 | テキスト | |
| ケダモノの性格 | テキスト | |
| 疑似餌の性格 | テキスト | |
| その他設定 | テキスト | |
| コピー | 数式 | [notion-formula.txt](notion-formula.txt) の内容 |

数式の `YOUR-DOMAIN` は、Notionサイトのドメインに置き換えてください。

## 出力の形式

- CS URL以外をコードブロックで囲みます。URLはブロックの外に出します。
- 空欄の項目は出力しません。
- `【CS URL】` のページをほかの人が開くには、そのページのWeb公開が必要です。
